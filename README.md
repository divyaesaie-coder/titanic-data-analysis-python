# Titanic Data Analysis Project

## Project Overview
This project performs data analysis and visualization using the Titanic dataset with Python libraries like Pandas, Matplotlib, and Seaborn.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Features
- Loaded CSV dataset
- Data cleaning
- Missing value handling
- Statistical analysis
- Correlation analysis
- Data visualization

## Visualizations
- Bar Chart
- Scatter Plot
- Heatmap
- Pie Chart
- Histogram

## Observations
1. Female passengers had higher survival rates.
2. Most passengers belonged to 3rd class.
3. Passenger fares varied significantly.
4. Younger passengers were more common.
5. Passenger class affected survival chances.

## Conclusion
The project demonstrates how Python can be used for data analysis, visualization, and extracting meaningful insights from datasets.
